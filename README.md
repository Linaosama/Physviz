# PhysViz · 物理公式实验台

PhysViz 是一款用 Python + pygame 编写的交互式 2D 物理可视化工具。核心理念是 **公式即物体**：
在画布上拖动字母、数字和符号拼出物理公式，公式被识别后会变成具备对应物理性质的实体，
并在屏幕上实时演示这条公式的效果。适合中学 / 大学物理教学演示与自学。

当前版本：**v0.2**

## 功能亮点

- **拖拽拼公式**：字母（Times New Roman 斜体）、数字与符号（直立）拼成公式，分数自动上下排版，支持上下标（v₀、v²）。
- **公式生成物体**：识别后的公式卡片可直接双击 / 点"生成"变成对应物体，也可拖到小球上叠加效果。
- **经典力学**：重力（mg）、抛体运动与 vx / vy 速度分解、外力（F=ma）、动量与动能（p=mv、E=½mv²）、摩擦力（f=μN）、重力势能（E_p=mgh）、匀变速（v=v₀+at）、功（W=Fs）。
- **碰撞演示**：任意两球相撞按动量守恒与能量守恒求解，面板列出碰前 / 碰后速度及总动量、总动能。
- **天体与黑洞**：E=mc² 变黑洞（真实引力、事件视界、吸积盘、吞噬并守恒动量）；G=mv²/r 与 F=GMm/r² 生成恒星，支持 N 体引力、双星 / 三星系统、恒星合并。
- **环境参数**：每个模拟可独立设置 g、空气阻力 f=kv、地面动摩擦因数 μ、恢复系数 e、引力常数与全局重力开关。
- **桌子与隔板**：桌子可调宽高 / 摩擦 / 反弹；隔板完全阻隔碰撞与引力。
- **多模拟标签页**：模拟 1、模拟 2 …… 互相隔离，可随时新增、切换、关闭。
- **属性面板**：编辑质量、速度、方向、外力、桌子 / 隔板参数，一键删除任意物体（包括黑洞）。

## 安装与运行

需要 Python 3.10 及以上。

```bash
pip install -r requirements.txt
python main.py
```

Windows 若提示找不到 `python`，可尝试 `py main.py`。

打包成可执行文件（可选）：

```bash
pip install pyinstaller
pyinstaller -F -w main.py
```

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 点击 / 拖动右上角字母、符号 | 生成 token；靠近其他 token 自动拼成公式 |
| 点击"小球 / 桌子 / 隔板 / 双星 / 三星" | 在画布中生成对应物体（拖动可指定位置） |
| 双击公式卡片 或 点"生成" | 按公式生成对应物体（小球 / 恒星 / 黑洞） |
| 拖公式卡片到小球上 | 为小球叠加该公式效果 |
| 左键拖动并甩出 | 投掷物体 |
| 右键拖动带 F=ma 的小球 | 施加外力 |
| 右键点击 token / 卡片 | 删除 |
| 选中物体后右侧"属性"面板 | 修改参数、回车应用、"删除" |
| 右下"环境"面板 | 修改 g、空气 k、地面 μ、反弹 e、G_sim、全局重力 |
| 顶部标签 / `+` / `×` | 切换、新增、关闭模拟 |
| `Space` / `R` / `Delete` | 暂停 / 重置当前模拟 / 删除选中 |

## 已支持的公式

| 公式 | 效果 |
| --- | --- |
| `mg` | 赋予重力，显示抛物线轨迹与速度分解 |
| `F=ma` | 可右键拖动施加外力 |
| `p=mv` | 显示动量 |
| `E=½mv²` | 显示动能 |
| `E=mc²` | 坍缩为黑洞 |
| `G=mv²/r` | 生成恒星 / 中心天体，附近小球可做圆周运动 |
| `F=GMm/r²` | 显示引力大小 |
| `f=μN` | 显示摩擦力 |
| `E_p=mgh` | 显示重力势能 |
| `v=v_0+at` | 显示速度随时间变化 |
| `W=Fs` | 显示外力做功 |

## 字体

- 程序会按 Windows / macOS / Linux 常见路径自动查找中文字体，并递归查找文件名含
  `FZS10`、`方正S10`、`FZShuSong`、`方正书宋`、`FZSSJW` 的方正字体。
- 公式中的拉丁字母使用 Times New Roman（缺失时用 Liberation Serif）斜体；数字、单位、运算符与汉字使用直立字体。
- 若中文显示乱码，在项目根目录创建 `assets/fonts/`，放入任意中文字体并命名为
  `cjk.ttf` / `cjk.ttc` / `cjk.otf`，程序会优先使用它。

## 项目结构

```
main.py              入口
physviz/app.py       主循环、事件处理、多模拟标签
physviz/physics.py   物理引擎（重力、摩擦、空气阻力、碰撞、N 体引力、黑洞）
physviz/entities.py  Token、公式链、物体（小球 / 恒星 / 黑洞 / 桌子 / 隔板）
physviz/formulas.py  公式识别与注册表
physviz/effects.py   轨迹、箭头、黑洞等视觉效果
physviz/ui.py        面板、输入框、属性 / 环境面板
physviz/fonts.py     字体查找与公式排版（上下标、分数）
tests/               pytest 冒烟测试
```

## 物理约定

100 px = 1 m，固定步长 1/240 s；默认 g = 9.8 m/s²，恢复系数 0.9，空气阻力与地面摩擦默认为 0。
